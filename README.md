# CarmenFit Coach

Aplicație pentru antrenamente CarmenFit pe 3 blocuri (A, B, C × 3 exerciții).

- **Generate**: creează un antrenament nou pentru Deva sau Cluj, respectând regulile fixe (fără deadlifts, Dumbbell Shoulder Press, leg press izolat per picior, Kneeling Cable Glute Kickback doar la Deva, nume în engleză).
- **Preferințele de azi**: cereri speciale (ex. „Banded Hip Thrust la 1A”).
- **Copy**: text curat, fără câmpuri goale, gata de lipit în Google Calendar.
- **Gamification**: obiectiv 3 antrenamente / săptămână, streak de săptămâni, XP, niveluri, badge-uri, misiunea zilei.
- **Progresie**: feedback-ul salvat după fiecare antrenament (kg, ce a fost greu) e folosit la următoarea generare.

Generarea și salvarea funcționează în versiunea publicată în Claude (folosește Claude pentru generare și baza de date a artifactului).
